# team-project-access

Учебный проект по дисциплине «Моделирование и анализ программного обеспечения» (МИАПО).
Практическое занятие №7 — настройка доступа к репозиторию.

## Параметры репозитория

- Основная ветка: **main**
- Защита ветки: Pull Request + 1 обязательный ревьюер
- Правило действует и для администраторов (**Include administrators**)
- Прямые коммиты в `main` запрещены

## Файлы

- `CONTRIBUTORS.md` — список участников, добавленный через Pull Request;
- `report-access.txt` — ответы на контрольные вопросы;
- `.github/CODEOWNERS` — владелец кода;
- `NOTES.md` — сведения об ограничениях бесплатного тарифа GitHub.

## Проверка настроек

1. Settings → Branches → Branch protection rules.
2. Правило для `main` включено.
3. Прямой коммит в `main` запрещён: GitHub предлагает создать отдельную ветку и Pull Request.

## Примечание о тарифе

На бесплатном тарифе GitHub (Free) защита веток недоступна для приватных репозиториев.
Чтобы правило защиты `main` реально работало и его можно было продемонстрировать,
репозиторий опубликован (Public). Для приватного варианта требуется GitHub Pro;
студентам он доступен бесплатно через GitHub Student Developer Pack.
